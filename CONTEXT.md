# Reflective Journal

A submission type for Moodle Assignments in which a student builds up a series of reflective Entries over time, which tutors can Comment on as they go and which receives a single Grade at the end.

## Language

**Journal**:
One student's complete set of Entries within a single Assignment; it is graded as one whole.
_Avoid_: Submission (ambiguous with Moodle's own term), diary, log

**Entry**:
One saved piece of reflective writing within a Journal, labelled "Entry N" with the date it was saved. A Journal holds up to a teacher-set maximum number of Entries; there is no minimum. Each Entry records the Reflective Model chosen for it.
_Avoid_: Post, page, week, section

**Edit Window**:
The period that runs until 15 minutes after an Entry or Comment was last saved. During it the author can still change it and nobody else can see it. An Entry still in its Edit Window at Journal Submission is Locked automatically.
_Avoid_: Grace period, draft period

**Locked**:
The state of an Entry or Comment once its Edit Window has closed: it can't be changed or removed, and the other party can now see it.
_Avoid_: Final save, published, finalised

**Reflective Model**:
The reflective framework (Gibbs, Driscoll, Kolb, or None) the student chooses, which decides which Reflective Prompt they see while writing.
_Avoid_: Template, framework, cycle

**Reflective Prompt**:
Fixed guidance text for the chosen Reflective Model, shown in a panel beside the editor while the student writes an Entry.
_Avoid_: Question, hint

**Tutor**:
The student's allocated marker for the Assignment (the first one, if several are allocated). They are notified about Entries and write the Comments. If no marker is allocated, anyone who can grade acts as the Tutor.
_Avoid_: Marker, grader, teacher (the teacher sets up the Journal; the Tutor is the one assigned to a student)

**Comment**:
A tutor's single formative note on one Locked Entry, written before Journal Submission. The student can read it but can't reply. It is separate from Feedback and doesn't count towards the Grade.
_Avoid_: Feedback, annotation, reply

**Grade**:
The single summative mark given to the whole submitted Journal through normal Assignment grading.
_Avoid_: Mark per entry, score

**Feedback**:
The tutor's summative written response on the marking screen after Journal Submission, as for any Assignment. It is not the same as a Comment.
_Avoid_: Comment

**Journal Submission**:
The point at which the whole Journal, with its Comments, is handed in for marking. After it, no more Entries or Comments can be added. It always happens automatically at the latest of the due date, cut-off date and the student's extension date, and it can happen earlier if the Submission Mode allows it.
_Avoid_: Final save, submit entry

**Submission Mode**:
The teacher's setting that decides whether the student also gets a "Submit the whole journal" button for early submission, or whether the deadline is the only trigger.
